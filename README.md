## 这东西解决什么问题

Telegram 官方的「导出数据」有个硬伤：**导出来的群列表里没有 @用户名**。
它明确知道哪些群是公开的（源码里就判断了 `chat->username`），但就是不写进文件。

结果就是：你以为备份好了，真出事想加回去的时候，**发现只有一堆看不懂的数字 ID**。

这个工具把这件事补上：**@用户名、能点开的链接、成员数、最后活跃时间，全都给你列出来**。

## 导出的表格里有四张表

| 表名 | 内容 |
|---|---|
| **群组和频道** | 类型、名称、**@用户名**、**可点击链接**、**链接状态**、成员数、最后消息时间、ID |
| **机器人** | @用户名、昵称、最后聊天时间、ID |
| **联系人** | 姓名、手机号、@用户名、ID |
| **统计** | 一共多少群、多少公开、多少拿到链接 |

`链接状态` 这一列是重点，它告诉你每个群的链接到底能不能用：

| 状态 | 意思 |
|---|---|
| `公开链接` | 直接能点，永久有效 |
| `已生成邀请链接` | **私有群也拿到了**，别人做不到 |
| `需管理员权限` | 你不是管理员，电报不让给 —— 这是官方限制 |
| `限流，需等 N 秒` | 群太多电报在压速，等一会重试 |

## 怎么用（四步）

1. **双击 `TelegramBackup.exe`**
2. **选国家，填手机号**（不用管前面的 0，程序自己处理）
3. **点「一键导出」**
4. **把手机上收到的验证码填进去** —— 完成，Excel 自动出现在桌面

就这么简单。不需要选保存位置，不需要打开命令行，不需要改任何配置。

> 验证码是**电报 App 里收到的一条消息**，不是短信。如果你开了两步验证，会再让你输一次密码。

## 常见问题

**Q：连不上，一直转圈？**
先确认代理软件开着，并且能正常上网。程序会自动识别本机代理。

**Q：提示「电报让你等 N 秒」？**
说明你群太多，或者用的是公开 api_id 被别人拖累了。等一会再点。想更稳就自己申请 api_id（见下方「高级」）。

**Q：为什么联系人那栏经常是空的？**
电报的「联系人」只有你**主动保存过号码**的人才算。只是聊过天、在会话列表里的人不算。这是电报的规则，不是工具的问题。

**Q：私有群的链接拿不到？**
必须是那个群的管理员才能生成邀请链接，普通成员拿不到。这是 Telegram 的硬限制，任何工具都绕不过去。

**Q：我的数据会被上传吗？**
**不会。** 全部在你的电脑本地完成，导出的 Excel 直接存到桌面。程序不联网上传任何东西，作者也拿不到你的任何数据。

**Q：安全吗？要我的密码吗？**
不要密码。第一次登录时电报会把验证码发给你，只有拿到验证码才能登。登录凭据保存在你本机的 `%APPDATA%\TelegramBackup\` 里，不会外传。

## 高级：换一个自己的 api_id

程序默认用一个公开的程序身份（`2040`），好处是你什么都不用配。坏处是用的人多了电报会限流。

想更稳定，去 https://my.telegram.org → API development tools 建一个应用（名字随便填），
把拿到的 `api_id` 和 `api_hash` 填进程序的「高级设置」里，以后就不用管了。三分钟，永久有效。
